# KinetiSub free tester privacy notice

Effective date: October 14, 2026.

The Windows and Android tester builds process videos, audio and subtitles on the user's device. No KinetiSub account is required, and the app does not send these files to a KinetiSub server.

Preferences are stored locally. Temporary encoder files may use app-private scratch storage and are released after export. Completed files are saved where the user chooses. Editable caption/video sessions are not automatically saved; closing the app loses unexported session edits.

This Windows tester has no live advertising, purchase flow or application analytics. Opening external help, source, privacy or feedback links uses the receiving service's policies. Downloading the app from GitHub and obtaining Microsoft WebView2 involve those services; those are distinct from uploading user media.

The Android developer tester uses Google AdMob test identifiers and User Messaging Platform consent handling. It can request test ads following successful exports, capped at two attempts per local day. Google SDK requests may process IP address, device information, identifiers and diagnostics according to [Google's advertising privacy information](https://policies.google.com/technologies/ads). Media files are not sent as ad-request content. Test ads do not earn revenue. Privacy choices are accessible in the app's settings. The Windows build does not request these native Android ads.

There is no purchase flow, automatic transcription or application analytics. Android production advertising, billing, the final policy and Google Play Data safety declarations require review against the final signed build before that launch.

Public GitHub feedback issues are visible to other people. Do not include private media, personal data, passwords or tokens. Close/delete content through GitHub if you independently publish it there.

Questions may be raised through this repository's issues. This notice describes the tester build's current behavior; it is not a security certification.
